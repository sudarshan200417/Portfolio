# Run the portfolio locally

1. Extract this folder.
2. Double-click `start-demo.bat` on Windows, or run `python -m http.server 8000` in this folder.
3. Open `http://localhost:8000`.
4. Click **Software and AI**, **Security (SOC)**, or **Salesforce Admin**.
5. Click **Download resume**. The corresponding PDF should download.

The resume mapping is in `js/script.js` under `RESUMES`.
